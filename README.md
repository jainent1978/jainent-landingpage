## ✨ Features & Architecture

- **Luxury Showroom Aesthetics**: Warm Gold (`#D4A64A`), Charcoal (`#111111`), and Clean White (`#FFFFFF`).
- **Day & Night Mode**: Custom glowing bulb toggle with frosted glassmorphism header in both themes.
- **Auto-Hiding Smart Navbar**: Smooth scroll detection hides the navigation bar on scroll down and reveals it when scrolling up.
- **Infinite Brand Marquee**: Smooth continuous ticker displaying all 21 authorized brand partners in full color (Havells, Polycab, Finolex, Crompton, Schneider, Orient, Jaquar Lighting, etc.).
- **Product Categories (AI Photorealistic Images)**:
  1. **Lights**: Panel and concealed LED ceiling lights.
  2. **Geysers**: Modern smart digital water heaters.
  3. **Fans**: BLDC decorative ceiling fan, wall fan, and exhaust fan.
  4. **Electrical Hardware**: Rigid PVC conduit pipes, 90° bends, 4-way circular junction boxes, and flexible pipes.
  5. **Accessories**: SPN/TPN modular MCB distribution boxes, switch plates, and surge extension boards.
  6. **Wires & Cables**: Multi-strand pure copper house wiring cable coils.
- **Interactive Product Modal**: Detailed technical specifications, gauges, and range for each category with instant WhatsApp inquiry dispatch.
- **Real Google Reviews**: Verified customer reviews from actual clients with authentic reviewer profile avatars.
- **Interactive Showroom Map**: Embedded live Google Map with "Get Directions" and verified Google Profile link.
- **Direct WhatsApp Conversion**: Inquiry form and floating beacon button route customers directly to WhatsApp with pre-filled order details.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or launch a lightweight local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

Visit `http://localhost:8000` to preview.
